# Corpus latihan lokal untuk eksperimen tokenisasi, BPE, dan demo n-gram.
# Sengaja kecil, berulang, dan sepenuhnya offline. Kosakata dibuat sempit
# supaya merge BPE mulai terlihat setelah beberapa puluh iterasi saja.

model bahasa belajar memprediksi token berikutnya. untuk memprediksi token
berikutnya, model bahasa membaca urutan token dan mengembalikan probabilitas
untuk setiap token di dalam kosakatanya. kosakata adalah daftar token yang
tetap, dan setiap token dipetakan ke satu id bilangan bulat. tokenisasi adalah
proses yang mengubah teks mentah menjadi urutan id token. tokenizer yang baik
menjaga kata umum sebagai satu token dan memecah kata langka menjadi potongan
yang lebih kecil.

transformer adalah tumpukan blok dekoder. setiap blok dekoder berisi satu
lapisan atensi dan satu jaringan feed forward. atensi membuat setiap token bisa
melihat token sebelumnya, dan mask kausal mencegah token melihat masa depan.
jaringan feed forward mengubah setiap token secara sendiri. normalisasi lapisan
menjaga aktivasi tetap stabil, dan koneksi residual menjaga gradien tetap
mengalir.

inferensi adalah proses menghasilkan teks dengan model yang sudah dilatih.
model menghasilkan satu token setiap kali, lalu menambahkan token baru itu ke
urutan. cache key value menyimpan kunci dan nilai atensi supaya token sebelumnya
tidak dihitung ulang. cache tumbuh bersama panjang konteks, dan cache adalah
alasan utama kenapa inferensi konteks panjang membutuhkan memori lebih besar.

temperatur mengubah bentuk distribusi token berikutnya. temperatur rendah
membuat distribusi tajam, dan temperatur tinggi membuat distribusi datar.
sampling top k hanya menyimpan k token yang paling mungkin, dan sampling top p
menyimpan himpunan token terkecil yang massa probabilitasnya di atas p. decoding
greedy selalu memilih token yang paling mungkin, dan beam search menyimpan
beberapa kandidat urutan.

fine tuning memperbarui bobot model pada dataset baru. lora membekukan bobot
asli lalu melatih dua matriks kecil sebagai gantinya. kuantisasi menyimpan bobot
dengan bit yang lebih sedikit, sehingga mengurangi memori dengan mengorbankan
sedikit presisi. retrieval augmented generation menambahkan dokumen eksternal ke
prompt, bukan mengubah bobot. setiap metode menukar memori, latensi, dan
kualitas dengan cara yang berbeda, dan pilihan yang tepat bergantung pada
tugasnya.

token adalah satuan yang dilihat model. token bukan kata dan token bukan
karakter. kata umum menjadi satu token, sedangkan kata langka dan tanda baca
yang tidak biasa menjadi beberapa token. context window adalah jumlah maksimum
token yang bisa dibaca model sekaligus. ketika prompt lebih panjang dari context
window, token paling lama harus dibuang atau dipadatkan.
